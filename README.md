# App Contaduría · Sol-EMP

App web para contadores de **Sol-EMP Soluciones Empresariales**: calcula el IVA y el ISR mensual de cada cliente, lee los XML y ZIP del SAT, hace facturas para timbrar, recibos y cotizaciones, y prepara la declaración anual.

- Tablas 2026: tarifa ISR mensual y anual del Anexo 8 de la RMF, tasas RESICO (art. 113-E LISR), UMA 2026.
- Regímenes: RESICO (626), Actividad empresarial y profesional (612), Arrendamiento (606), Plataformas tecnológicas (625), Sueldos y salarios (605) y Personas morales (601).
- Los datos se guardan en el navegador del dispositivo. Usa **Respaldo** para descargar y restaurar la información.

Es una hoja de trabajo: los resultados se revisan contra la declaración en el portal del SAT.

Hecha por Supernova.
